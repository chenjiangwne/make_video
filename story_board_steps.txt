# story_board.txt 制作拆解 · 让成片尽量贴合原稿

> 源文件：`story_board.txt`
> 目标：180 秒 / 1920×1080 / 30fps / 黑金光影风 / 中文字幕 + 口播
> 原则：**旁白不改写，只拆分；结构不增删，只落地；画面按原稿的关键动作设计。**
> 建议新开一期 `ep54-national-debt-story`，保留现有 ep53 作为草稿，不覆盖。

---

## 0. 总原则：一个时间源，三层复用

1. **时间源只有一个**：`story_board.txt` 的六段时间 + 拆出来的 SRT/voice-plan。  
   所有字幕、镜头、音效、BGM 段落都从它推导，不再手写第二套时间。
2. **结构严格照原稿**：  
   钩子（0-12）→ 内债/外债（12-40）→ 情景 1（40-75）→ 情景 2（75-110）→ 情景 3（110-145）→ 普通人（145-165）→ 总结（165-176）→ 结尾（176-180）。
3. **画面复用 60%–70%**：`BillG`（欠条）、`WalletG`（现金）、`GlowCard`（分栏/卡片）、`NeonLines`（汇率曲线）、`ShockG`（冲击）、`GlowBars`（债务山）、`SparkTitle` / `ChapterTag` / `BGCaption`。  
   只为本期新做 3 个左右专属组件：国家小人、欠条堆、债务山/情景画面。
4. **不照搬 ep53 的叙事**：ep53 有「银行—主权循环」等段落，原稿没有；这次不要混进去。可以复用 ep53 的**代码组件**，不能复用它的 `CUES` 和结构。

## 1. 第一步：提取旁白，做字幕稿 + SRT + 配音计划

### 1.1 参考格式

参考：`products/ep52-microwave-target-subtitles.md`（表 + SRT）。  
输出到：`products/one/story-board/`

- `字幕稿.md`：序号 | 时间 | 中文 | English（可选）| 对应段落 | 画面提示
- `字幕.srt`：剪辑软件/播放器可直接挂
- `voice-plan.json`：给 `audio/tts_lines.py` 用（id / start / end / window / text）

### 1.2 拆分规则

- **旁白原文不改写**，只在标点处拆；一句话太长就拆成 2–3 条字幕。
- 每条中文 ≤18 字（按项目黑金/暗金字幕规则）；超过就拆，不要压字号。
- 每条 3–5 秒；全片大约 **45–52 条**。
- 每条都要落在所属段落内；段与段之间留 0.2–0.5 秒呼吸。
- 字幕与口播共用同一套时间；口播用 TTS 或真人录音，不另写一版。

### 1.3 分段与行数预估

| 段落 | 原稿时间 | 建议条数 | 内容 |
|---|---:|---:|---|
| 钩子 | 0–12s | 4–5 | 国家欠债太多会怎样 + 普通人的存款/工资 |
| 两种债 | 12–40s | 8–9 | 内债 vs 外债，钱在国内/国外循环 |
| 情景 1 | 40–75s | 10–11 | 慢慢拖、通胀、税收、增长；购买力缩水 |
| 情景 2 | 75–110s | 10–11 | 外储不够、资本外流、汇率暴跌、输入性通胀、失业 |
| 情景 3 | 110–145s | 9–10 | 违约、失去海外融资、股市/银行/挤兑风险 |
| 普通人 | 145–165s | 6–7 | 存款分散、避开单一资产、不要盲目加杠杆 |
| 总结 | 165–176s | 4–5 | 债务不是洪水猛兽，失控才是 |
| 结尾 | 176–180s | 1–2 | 下一期 + 点赞关注 |

> 如果口播用 TTS，先跑 `audio/tts_lines.py` 校验时长；任何一句超过窗口就提高语速或再拆一句，**不要靠拉长镜头硬塞**。

### 1.4 验收

- [ ] 每条 ≤18 字，且是完整可读的半句/整句
- [ ] 所有旁白原文都出现，没有改写、没有漏句
- [ ] 每条都在所属段落内，没有跨段
- [ ] 口播 45–52 句全部 fit，没有重叠
- [ ] `字幕稿.md`、`字幕.srt`、`voice-plan.json` 三份时间一致

## 2. 第二步：画面实现（按原稿逐段落地）

### 2.1 镜头切分建议（按 120 BPM / 2 秒小节吸附）

原稿切点 75 / 145 / 165 与 2 秒小节差 1 秒；建议吸附为 **74 / 144 / 164**，其余 12 / 40 / 110 / 176 本来就是小节线。若你要求严格 75/145/165，也可以不吸附，BGM 段落按最近小节进。

| 镜头 | 时间 | 画面任务 | 复用/新做 |
|---|---:|---|---|
| S01 钩子 | 0–12 | 国家小人不断签欠条，欠条越堆越高，最后压住小人；标题弹出 | 新做 `CountryG` + `BillStackG`；复用 `SparkTitle` |
| S02 两种债 | 12–40 | 左右分栏：内债（国债/地方债，钱在国内循环）vs 外债（外币偿还，资本外流）；中间「内债 ≠ 外债」 | 复用 `GlowCard`、`BillG`、`WalletG`；新做简单图标 |
| S03 情景 1 | 40–74 | 债务小山缓慢上涨；央行、税收图标交替；箭头流动；没有爆炸；暖色/中性 | 复用 `GlowBars`/`NeonLines`；新做 `DebtHillG` |
| S04 情景 2 | 74–110 | 外币流出；汇率曲线断崖；本币贬值；银行告警；红烟 | 复用 `NeonLines`、`ShockG`、`BillG`；加告警图标 |
| S05 情景 3 | 110–144 | 欠条打红叉；债券图标失效；画面雪花/抖动；红黑 | 复用 `BillG`、`ShockG`；新做红叉/失效印章 |
| S06 普通人 | 144–164 | 三张卡片依次弹出：存款分散 / 避开单一资产 / 不要盲目加杠杆 | 复用 `GlowCard`、`WalletG` |
| S07 总结 | 164–176 | 镜头拉远，回到欠条堆；总结文字浮上来 | 复用 `BillStackG`、`CenterWord` |
| S08 结尾 | 176–180 | 片尾固定模板 + 下一期预告 + 点赞关注 | 复用 `SparkTitle`/`EndCard` 风格 |

### 2.2 新组件清单（约 3 个）

1. `CountryG`：发光的小人 + 简化的国旗/地块轮廓（不要真实国旗/真实地图边界），支持「被欠条压住」的姿势。
2. `BillStackG`：多张 `BillG` 按关键帧往上堆，最后盖住国家小人；可复用 `BillG`。
3. `DebtHillG`：缓慢升高的债务山（可用 `GlowBars` 变形或 `NeonLines` 面积图），配央行/税收图标。

其余全部复用：`BillG`、`WalletG`、`GlowCard`、`NeonLines`、`ShockG`、`GlowBars`、`SparkTitle`、`ChapterTag`、`CiteLine`、`BGCaption`、`SmokeBg`、`Grain`。

### 2.3 画面验收

- [ ] 每个原稿段落至少有一个「原稿里写到的动作」：欠条堆、左右分栏、债务山、汇率断崖、红叉、三张卡片、镜头拉远
- [ ] 情景 1 不出现爆炸/崩盘；情景 2/3 才用红烟、冲击、抖动
- [ ] 内债/外债的颜色和图标必须一眼能分：内债金/青，外债红/外币符号
- [ ] 不出现真实国旗、真实银行 logo、真实人物
- [ ] 180 秒里没有「只有字幕、画面不动」超过 2 秒的段落

## 3. 第三步：音效与 BGM

### 3.1 口播

- 首选真人录音；没有就用 TTS（云扬/晓晓），先做试听版。
- 用 `audio/tts_lines.py` 读 `voice-plan.json`，输出 `voice.wav`；全部 fit 再进混音。
- 口播响度约 −17 到 −18 LUFS；BGM 在说话时闪避。

### 3.2 BGM 段落

现有 `bgm-variants/` 四条 120 BPM 试听：current / cinematic-dark / minimal-pulse / news-urgent。推荐两种方案：

**方案 A：单曲铺满（最稳）**
- 0–74：`cinematic-dark` 或 `current` 的 light/groove
- 74–144：切 `news-urgent` / tense
- 144–180：回 `minimal-pulse` 或 `break/end`
- 只换段落，不换曲，统一感最好。

**方案 B：hybrid（更贴剧情）**
- 0–12 钩子：cinematic 低频 + 心跳
- 12–40 两种债：minimal 干净、少鼓
- 40–74 情景 1：current light/groove（温和）
- 74–110 情景 2：news/tense（紧迫）
- 110–144 情景 3：cinematic + 重 impact（危机）
- 144–164 普通人：minimal/light（冷静建议）
- 164–180 总结/结尾：cinematic 收束 + end 和弦

> 所有变体都是 120 BPM；若要 72/90 BPM，必须同步重排 `timeline.ts` 的小节和镜头，不能只换音频。

### 3.3 音效表（按段落）

| 时间 | 音效 | 作用 |
|---|---|---|
| 0–12 | paper / stamp / 欠条叠加的轻响 | 欠条越堆越高 |
| 12 | whoosh + 分栏展开 | 进入「两种债」 |
| 40 | 低频 pulse + 硬币/税收 tick | 情景 1 开始，温和 |
| 74–75 | riser + 汇率告警 tick | 情景 2 转紧张 |
| 90–110 | warning beep / impact | 汇率断崖、银行告警 |
| 110 | impact + 红叉 stamp | 情景 3 违约 |
| 110–144 | 雪花噪声 / 抖动 / 低频 | 市场失效 |
| 144–164 | 三张卡片 pop（轻） | 建议卡片依次出现 |
| 164–176 | 拉远 whoosh + 低频收束 | 回到欠条堆 |
| 176–180 | chime / end 和弦 | 片尾 |

复用 `audio/sfx/` 里的 `paper`、`stamp`、`whoosh`、`ding`、`error`、`tick`，以及 `makeTacticalSfx` 的 `impact`/`riser`/`tick`。

### 3.4 混音

- 人声先归一化到约 −18 LUFS；
- BGM 侧链闪避（threshold 0.02 / ratio 8 / attack 15ms / release 300ms）；
- SFX 低一层（约 0.5–0.6）；
- 最终限幅到 −1.5 dBTP，整体约 −16 LUFS。

## 5. 实现难度

| 步骤 | 难度 | 预计耗时 | 说明 |
|---|---|---:|---|
| 1. 旁白提取 + 字幕/SRT + voice-plan | 低 | 1–2 小时 | 原稿清楚，主要是拆分、对齐、TTS 时长校验 |
| 2. 画面实现 | **中高** | 1.5–2.5 天 | 新做国家小人、欠条堆、债务山；三情景要有明显区分；180 秒节奏长 |
| 3. 音效 + BGM + 混音 | 中 | 0.5–1 天 | BGM 变体已有；要做段落切换、口播闪避、SFX 表 |
| 4. 组装 / 测试 / 渲染 / QA | 中 | 0.5 天 | 5400 帧，渲染约 6 分钟；抽帧和响度检查 |
| **合计** | **中高** | **约 3–4 天（精修）** | 用 TTS + 复用 ep53 组件可压到 2 天左右；真人配音会再多 0.5–1 天 |

### 主要风险点

1. **国家小人**：既要有“国家”的识别度，又不能画真实国旗/边界；建议抽象发光人 + 简化地块/旗帜符号。
2. **三种情景的视觉区分**：温和（暖金）→ 危机（红）→ 违约（红黑 + 雪花），颜色和镜头语言必须分开，否则观众会混。
3. **180 秒的节奏**：原稿信息量大，45–52 条字幕；不要为了画面留白牺牲旁白，也不要让字幕压满。
4. **内债/外债的准确性**：原稿是简化表达；建议在画面角落保留「示意」或一句限定（本币/外币、币种错配），避免绝对化。
5. **违约概率**：原稿说“大国走到这一步概率极低”；保留“通常/概率低”的限定，不要剪成“必然发生”。
6. **BGM 与切点**：120 BPM 小节是 2 秒；原稿 75/145/165 与小节差 1 秒，建议吸附或让 BGM 从最近小节进。
7. **TTS 味**：试听版可以；正式发布建议真人录音或更好的 TTS，尤其是“存款、工资、购买力”这种情绪句。

### 结论

技术难度不高（项目已经支持 180 秒、角色、图表、TTS、BGM、混音），**真正的工作量在画面叙事**：把“欠条堆 → 内债/外债 → 三种结局 → 三张建议卡 → 拉远总结”这五组视觉动作做得清楚、有区别、不重复。按上面的步骤做，成片能比较贴近 `story_board.txt` 的结构和原话；建议先做 30 秒试片（0–40s）验证国家小人 + 分栏 + 口播节奏，再铺满 180 秒。
